فولدر الإشارات (JSON)
======================
حطّي هنا ملفات الجيسون اللي نزّلتيها من قاعدة البيانات، والكاميرا والأفاتار هيدوّروا عليها هنا.

الأشكال المقبولة (أي واحد منهم):
  1) ملف لكل إشارة:        مثال:  سلام.json   =>  { "word": "سلام", "fps": 30, "frames": [ ... ] }
  2) ملف فيه كل الإشارات:   [ { "word": "...", "frames": [...] }, { ... } ]
  3) ملف فيه { "signs": [ ... ] }
  4) سطر لكل إشارة (JSONL / NDJSON)

اسم الكلمة بيتاخد من أحد الحقول:  word / meaning / name / label / text / arabic / title
ولو مفيش، بيتاخد من اسم الملف.   مرادفات الكلمة (اختياري):  aliases / synonyms

الإحداثيات (frames) كل فريم فيه إيد شمال وإيد يمين، كل إيد 21 نقطة (x,y,z) من ميديا بايب.
بعد ما تحطي الملفات: اعملي ريفريش للصفحة بس (من غير أي إعداد تاني).
